# Contributing to Junex

Thank you for your interest in contributing to Junex.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Open the project in Android Studio.
4. Allow Gradle to synchronize dependencies.
5. Create a new branch for your changes.

## Development Guidelines

- Keep changes focused and clearly scoped.
- Follow the existing Kotlin and Jetpack Compose structure.
- Avoid unrelated formatting changes.
- Write clear and descriptive commit messages.
- Test changes before submitting a pull request.

## Pull Requests

When submitting a pull request:

- Clearly describe what changed.
- Explain why the change is needed.
- Include screenshots for UI changes when relevant.
- Ensure the application builds successfully.

## Reporting Issues

Use GitHub Issues to report bugs, suggest improvements, or discuss new features.

Please include enough information to reproduce the issue when reporting bugs.
